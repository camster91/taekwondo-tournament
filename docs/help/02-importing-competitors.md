# Importing Competitors

Learn how to bulk-import competitors from Excel or CSV files.

## Import Process

### 1. Download the Template

Go to **Competitors** → **Import from Excel** → **Download Template**. This gives you a pre-formatted spreadsheet with the correct columns.

### 2. Fill in Competitor Data

Required fields:
- **First Name**: Competitor's first name
- **Last Name**: Competitor's last name
- **Date of Birth**: Format: YYYY-MM-DD (e.g., 2010-03-15)
- **Gender**: M or F
- **Belt**: White, Yellow, Green, Blue, Red, Black
- **Weight (lbs)**: Current weight in pounds

Optional fields:
- **Belt Stripe**: e.g., "Single Green Stripe"
- **Dan Rank**: For black belts (1-6)
- **Height (inches)**: For reach-based matching
- **School/Dojang**: School name
- **Special Needs**: Accommodations or notes

### 3. Upload the File

Click **Choose File** and select your completed Excel file. The system will:
- Validate all data
- Show any errors (missing fields, invalid dates, etc.)
- Preview the import before finalizing

### 4. Review and Confirm

Check the preview list carefully:
- Verify names are spelled correctly
- Confirm ages and belts match your records
- Fix any validation errors

Click **Import** to add competitors to your registry.

## Tips

- **Keep a master list**: Maintain one Excel file with all your competitors and update it over time
- **Check for duplicates**: The system will warn you if a competitor already exists
- **Weight updates**: Update weights before each tournament for accurate division placement
- **School names**: Use consistent spelling (e.g., "Kim's TKD" not "Kims TKD")

## Troubleshooting

**"Invalid date format" error**: Dates must be YYYY-MM-DD (e.g., 2010-03-15, not 03/15/2010)

**"Duplicate competitor" warning**: A competitor with the same name and birthday already exists. Update the existing record instead.

**"Invalid belt" error**: Belt must be exactly: White, Yellow, Green, Blue, Red, or Black (case-sensitive)

## Auto-Mapping Columns

If your Excel file uses different column headers, use **Auto-Map Columns** to let the system detect your format. It will suggest mappings based on content analysis.
