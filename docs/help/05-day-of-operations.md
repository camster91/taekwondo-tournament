# Day-of Operations

Your guide to running a smooth tournament day.

## Pre-Event Checklist

- [ ] All divisions finalized and brackets generated
- [ ] Ring assignments confirmed
- [ ] Scorekeeper devices charged and tested
- [ ] Public scoreboard link shared with parents
- [ ] Printed brackets as backup
- [ ] Director dashboard open on command center device

## Check-In Process

### Purpose

Check-in verifies competitor attendance and records day-of weight for sparring divisions.

### Steps

1. Navigate to **Check-In** from the tournament page
2. Search for competitor by name
3. Record actual weight (sparring only)
4. Mark as **Checked In**
5. Note any last-minute changes

### Tips

- Set up check-in table near entrance
- Have two tablets/laptops for faster processing
- Check in patterns and sparring separately if needed
- Update special needs or accommodate requests

## Scoring Matches

### Scorekeeper View

1. Select your division from the dropdown
2. View all matches for that division
3. Click on a "Ready" match to begin scoring

### Recording Results

1. Select the winner
2. Enter scores for both competitors
3. Add any notes (injuries, DQs, etc.)
4. Click **Submit**
5. System automatically advances winner to next round

### Quick Scoring (Keyboard)

- **Arrow Keys**: Navigate between matches
- **1/2**: Select Competitor 1 or 2 as winner
- **Enter**: Submit result
- **Ctrl+Z**: Undo last result (5-minute window)

### Match Status

- **Pending**: Not ready to start
- **Ready**: Competitors present, can begin
- **In Progress**: Currently being scored
- **Completed**: Result recorded

## Director Dashboard

Monitor tournament progress in real-time.

### Key Metrics

- Total matches completed vs. remaining
- Division progress (percentage complete)
- Ring status and current matches
- Estimated completion time

### Ring Management

- Assign matches to specific rings
- Track which rings are active
- Rebalance rings if one gets ahead/behind

### Alerts

The dashboard shows warnings for:
- Divisions falling behind schedule
- Unresolved bye matches
- Missing competitors

## Public Scoreboard

### Sharing the Link

1. Go to **Tournament Settings** → **Public Scoreboard**
2. Generate a public link
3. Share via:
   - QR code posters at venue
   - Email to parents
   - Social media
   - Tournament website

### What Parents See

- Live bracket updates as matches complete
- Competitor search by name
- Full tournament results
- Next match information

### Display Options

- TV mode (4K-optimized, auto-refresh)
- Mobile-friendly view
- Print-friendly bracket view

## Troubleshooting

**"Scorekeeper offline"**: Scores are queued locally and sync when connection returns

**"Wrong winner recorded"**: Use Ctrl+Z immediately (5-min window) or contact director

**"Division behind schedule"**: Reassign matches to faster rings or add temporary ring

**"Competitor no-show"**: Mark as absent in check-in; they forfeit all matches

## Emergency Procedures

### Device Failure

1. Use printed bracket as backup
2. Record scores manually on paper
3. Enter results when device is back online

### Network Outage

- Offline mode activates automatically
- Scores queue locally
- Sync when connection restored

### Dispute Resolution

1. Pause the match
2. Note dispute in match notes
3. Director reviews and makes final call
4. Record official result

## Post-Tournament

1. **Results Export**: Download CSV/PDF of all results
2. **Certificates**: Generate and print placement certificates
3. **School Reports**: Email summary reports to each school
4. **Archive**: Tournament data is preserved automatically
