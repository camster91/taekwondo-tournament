# Public Registration

Enable competitors to self-register for your tournament online.

## Enabling Public Registration

### Requirements

- Tournament status set to "Registration Open"
- Public registration enabled in tournament settings
- Weight classes configured (for sparring)

### Setup Steps

1. Go to **Tournament Settings**
2. Enable **Public Registration**
3. Set registration deadline
4. Configure options:
   - Require parent/guardian info
   - Enable payment collection (optional)
   - Set registration limits

### Sharing the Registration Link

1. Generate the public registration URL
2. Share via:
   - Email to schools
   - Social media posts
   - Tournament website
   - QR code posters

## Registration Form Fields

### Competitor Information

- Name, date of birth, gender
- Current belt rank and school
- Weight (for sparring divisions)
- Event selection (patterns, sparring, or both)

### Parent/Guardian Information (for minors)

- Parent/guardian name
- Email address
- Phone number
- Emergency contact

### Consent & Waivers

- Rules acknowledgment
- Safety waiver
- Photo/video release (optional)
- Medical information (optional)

## Managing Registrations

### Review Submissions

All public registrations appear in your tournament's registration list with a "Public" tag.

### Verification Process

1. Review new registrations daily
2. Verify competitor information
3. Approve or reject submissions
4. Contact parents if information is missing

### Common Issues

**Duplicate registrations**: System checks for duplicates by name + birthday

**Missing information**: Contact parent to complete registration

**Age/belt verification**: Cross-reference with school records

## Payment Collection (Optional)

If enabled, competitors pay registration fees during signup:

- Set per-competitor fee in settings
- Stripe processes payments securely
- Automatic confirmation emails
- Refund handling through Stripe dashboard

## Registration Confirmation

After approval, competitors receive:
- Confirmation email with details
- Tournament date, time, location
- What to bring checklist
- Check-in instructions

## Waitlist Management

When divisions fill up:
- New registrations go to waitlist automatically
- Notify waitlist when spots open
- Set waitlist limits per division

## Closing Registration

1. Set registration deadline in settings
2. System automatically closes at deadline
3. Late registrations must go through director

## Best Practices

- **Open early**: Give competitors 4-6 weeks to register
- **Send reminders**: Email registrants 1 week and 1 day before
- **Monitor capacity**: Check division sizes regularly
- **Communicate changes**: Notify registrants of any schedule changes

## Troubleshooting

**"Registration link not working"**: Verify tournament status is "Registration Open"

**"Payment failed"**: Check Stripe configuration; contact registrant to retry

**"Confirmation email not received"**: Check spam folder; resend from system

**"Can't edit registration"**: Parents cannot edit after submission; contact director for changes
