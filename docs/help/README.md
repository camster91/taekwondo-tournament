## Quick Reference

### Common Tasks

- **Import competitors**: Competitors → Import from Excel → Upload file
- **Create divisions**: Divisions → Auto-Generate → Review → Apply
- **Generate brackets**: Division → Generate Bracket → Select format
- **Score matches**: Scorekeeper → Select division → Record results
- **View public scoreboard**: Tournament Settings → Public Scoreboard → Copy link

### Keyboard Shortcuts (Scorekeeper)

- **Arrow Keys**: Navigate between matches
- **1/2**: Select winner (Competitor 1 or 2)
- **Enter**: Submit result
- **Ctrl+Z**: Undo last result (5-minute window)
- **?**: Show help

### Support

- **Email**: support@bowin.io
- **Status**: status.bowin.io
- **Emergency** (tournament day): See pre-event email for phone number

## System Requirements

### Supported Browsers

- Google Chrome (recommended)
- Mozilla Firefox
- Apple Safari
- Microsoft Edge

### Internet Connection

- Minimum: 5 Mbps download/upload
- Recommended: 10+ Mbps for multi-ring operations
- Offline mode available for scorekeeper (scores sync when reconnected)

### Devices

- Desktop/laptop (preferred for setup and management)
- Tablet (great for scorekeeper and check-in)
- Mobile phone (public scoreboard, competitor search)
