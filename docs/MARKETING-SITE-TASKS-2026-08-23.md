# Bowin SaaS marketing site task list

## Goal

Sell Bowin as a martial arts tournament operations service through a truthful, accessible, search-ready product story that moves organizers from evaluation to the existing application.

## Completed in this implementation

- [x] Define evidence boundaries: no invented customers, metrics, testimonials, pricing, uptime, or security certifications.
- [x] Create desktop and mobile Figma flows using Simple Design System hero, button, and AI-chat templates as structural references.
- [x] Build a responsive acquisition flow: hero, product preview, workflow, audiences, AI support, evaluation CTA, FAQ, and final CTA.
- [x] Give organizers a primary path to `/login` and participants a path to `/register`.
- [x] Position AI support accurately: explain, gather context, use approved integrations, and escalate to human review.
- [x] Add page title, description, social metadata, canonical URL, and SoftwareApplication JSON-LD.
- [x] Add `sitemap.xml` and retain the existing `robots.txt` sitemap declaration.
- [x] Add semantic landmarks, keyboard focus, reduced-motion support, and native disclosure controls.
- [x] Add focused Playwright coverage for conversion links, SEO metadata, FAQ interaction, and mobile overflow.

## Production gates

- [ ] Select and configure a privacy/analytics platform before adding conversion tracking.
- [ ] Approve public pricing, trial language, testimonials, customer logos, or quantified proof before publishing them.
- [ ] Add reviewed privacy and terms pages before collecting new marketing-form data.
- [ ] Complete authenticated organizer, participant, official, and support-agent lifecycle QA in production.
- [ ] Approve VPS build-cache cleanup and deployment after reviewing the release revision and rollback target.
